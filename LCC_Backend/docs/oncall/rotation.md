# On-call Rotation

- 1 primary SRE per week
- 1 secondary SRE per week
- Handoff every Monday 10:00 UTC.

## Responsibilities

- Triage alerts from PagerDuty → route to service owners.
- Apply hotfixes via the standard change window (or hot-patch with
  dual-approval for SLO-impacting issues).
- Run the post-mortem for any incident.
